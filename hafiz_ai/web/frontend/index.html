      Telaffuz Çalışması

        Nasıl Çalışır?

        1. Çalışmak istediğin sure veya pasajı listeden seç.
        2. Kaydı Başlat butonuna tıkla, tarayıcın mikrofon izni isteyecektir.
        3. Okumaya başladığında Web Speech API konuşmanı metne çevirir, Hafız AI ise referans metinle anlık olarak karşılaştırır.
        4. Okumayı bitirdiğinde Kaydı Durdur butonu ile değerlendirmeyi tamamla ve önerileri incele.

        Not: Web Speech API tarayıcı tarafından sağlanır ve arabic (ar-SA) dil desteği gerekir. Desteklenmiyorsa manuel metin girişini kullanabilirsin.

        Demo amaçlı hazırlanmıştır. Daha gelişmiş telaffuz analizi için profesyonel ses modelleri entegre edilmelidir.
